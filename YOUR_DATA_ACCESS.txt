## QUICK ACTIONS

**Export to CSV:**
```bash
python3 /app/backend/export_waitlist.py
```

**View Data:**
```bash
python3 << 'EOF'
from pymongo import MongoClient
client = MongoClient('mongodb://localhost:27017/')
db = client['skillvore_db']
for entry in db.waitlist_signups.find():
    print(f"{entry['full_name']} - {entry['work_email']}")
client.close()
EOF
```

**Get Latest Signup:**
```bash
python3 << 'EOF'
from pymongo import MongoClient
client = MongoClient('mongodb://localhost:27017/')
latest = client['skillvore_db'].waitlist_signups.find_one(sort=[('created_at', -1)])
print(f"Latest: {latest['full_name']} ({latest['work_email']})")
client.close()
EOF
```
